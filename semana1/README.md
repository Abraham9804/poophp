# Semana 1 — Clases, objetos y tipos

## Conceptos

Clase vs objeto, propiedades y métodos, `$this`, constructor, promoción de propiedades en el constructor (PHP 8), tipos de retorno, `?tipo` y union types, `strict_types`, y objetos pasados por manejador (por qué modificar un objeto dentro de una función lo cambia fuera).
